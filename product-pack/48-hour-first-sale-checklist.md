# 48-Hour First Sale Checklist

## Hour 0-2: Choose one painful problem

- Pick one buyer type.
- Pick one painful before-after result.
- Write one sentence: "I help [person] get [result] without [pain]."

## Hour 2-6: Publish one offer page

- Add outcome.
- Add included files.
- Add price.
- Add no-guarantee/refund boundary.
- Add one checkout link.

## Hour 6-12: Connect lead capture

- Use workflow 01.
- Store name, email, pain, channel, status.
- Add lead score.

## Hour 12-24: Send ten useful messages

- Do not spam.
- Reply only where context fits.
- Ask one diagnostic question.
- Link only when relevant.

## Hour 24-36: Follow up

- Use workflow 03.
- Send one example.
- Ask if they want the template pack.

## Hour 36-48: Decide

- If no views: distribution problem.
- If views but no clicks: headline/offer problem.
- If clicks but no buys: trust/price/checkout problem.
- If buys: make a higher-priced setup offer.
